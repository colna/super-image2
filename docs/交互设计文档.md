# SuperImage2 — 交互设计文档

## 1. 设计原则

参考 Manus 的设计哲学，确立以下原则：

| 原则 | 说明 |
|------|------|
| **极简克制** | 界面只展示当前需要的信息，隐藏复杂度 |
| **内容优先** | 图片是主角，UI 是配角，大量留白让作品呼吸 |
| **流畅自然** | 交互反馈即时，动效轻柔，不打断创作心流 |
| **渐进展露** | 高级功能按需展露，新手不被吓到，老手不受限制 |

## 2. 视觉规范

### 2.1 色彩体系

```
背景层
├── 主背景        #FAFAFA (浅灰白，非纯白，减少视觉疲劳)
├── 侧边栏背景    #F5F5F5
├── 卡片/气泡背景  #FFFFFF
└── 悬停高亮      #F0F0F0

文字层
├── 主文字        #1A1A1A (接近纯黑，高可读性)
├── 次要文字      #666666
├── 占位文字      #BDBDBD
└── 链接/强调     #2563EB (蓝)

功能色
├── 主操作按钮    #1A1A1A (黑色实心，Manus 风格)
├── 成功状态      #22C55E
├── 错误状态      #EF4444
├── 生成中        #1A1A1A (脉冲动画)
└── 边框/分割线   #E5E5E5

暗色模式（预留，MVP 不实现）
├── 主背景        #0A0A0A
├── 卡片背景      #1A1A1A
├── 主文字        #EDEDED
└── 主操作按钮    #FFFFFF
```

### 2.2 字体

```
主字体:  Inter (英文) + "Noto Sans SC" (中文)
等宽:    "JetBrains Mono" (prompt 展示)
字号梯度: 13px (辅助) → 14px (正文) → 16px (标题) → 20px (页面标题)
行高:    1.6 (正文) → 1.4 (标题)
```

### 2.3 圆角与阴影

```
圆角:   8px (卡片/按钮) → 12px (对话气泡) → 16px (弹窗)
阴影:   无阴影优先；弹窗/下拉使用 0 2px 8px rgba(0,0,0,0.08)
边框:   1px solid #E5E5E5 (极细线分割)
```

### 2.4 间距

```
页面边距:     24px (桌面) → 16px (移动)
组件间距:     16px
气泡内边距:   16px 20px
侧边栏宽度:   280px (可折叠)
输入框区域高度: 60px (单行) → 最大 160px (多行)
```

```
  │  │                              │
  │  └──────────────────────────────┘

  │    │
  │    ▼
  │  ┌──────────────────────────────┐
  │  │                              │

  │  │                              │

  │  │  [赛博朋克风格的东京夜景]     │
```

### 4.2 生图核心流程

```
用户输入 prompt → 点击发送 / Enter
  │
  ▼
消息出现在对话流（右对齐，用户气泡）
  │
  ▼
AI 占位区出现（左对齐）
├── 骨架屏动画（图片尺寸的灰色矩形，脉冲闪烁）
├── 底部文字："正在生成..." + [取消] 按钮
  │
  ▼ (API 返回)
  │
  ├─ 成功
  │    图片淡入替换骨架屏（fade-in 300ms）
  │    图片下方展示：
  │    - revised prompt（折叠，点击展开）
  │    - 操作栏：[⬇ 下载] [📋 复制] [🔄 变体]
  │
  ├─ 内容审核拦截
  │    橙色提示条："此内容无法生成，请调整描述"
  │
  └─ 其他错误
       红色提示条：具体错误信息 + [重试] 按钮
```

### 4.3 会话管理流程

```
侧边栏操作：

[+ 新建会话]
  → 清空对话区，显示空状态/示例 prompt
  → 侧边栏新增条目并高亮

[点击历史会话]
  → 对话区平滑切换到该会话内容（cross-fade 200ms）
  → 自动滚动到最后一条消息

[右键会话]  /  [长按会话(移动端)]
  → 弹出菜单：重命名 | 删除
  → 删除需二次确认弹窗

[搜索会话]
  → 侧边栏顶部搜索框，实时过滤
  → 匹配标题和消息内容，高亮关键词
```

## 5. 组件交互细节

### 5.1 输入框

```
状态流转：
  空闲态  →  聚焦态（边框变深 #1A1A1A）
         →  输入态（发送按钮从灰变黑，可点击）
         →  生成中（输入框禁用，显示 "生成中..."）

行为：
  - Enter        → 发送（输入不为空时）
  - Shift+Enter  → 换行
  - ⌘+Enter      → 发送（备选）
  - 粘贴长文本   → 自动扩展高度，最大 160px，超出滚动
  - 空输入点发送  → 按钮抖动提示（shake 动画 300ms）
```

### 5.2 图片卡片

```
┌──────────────────────────────┐
│                              │
│      [生成的图片 原始PNG]     │
│      (点击查看原图预览)       │
│                              │
├──────────────────────────────┤
│ ▸ 查看修改后的 prompt         │  ← 折叠区
├──────────────────────────────┤
│ [⬇ 下载原图] [📋 复制] [✏ 编辑]│  ← 操作栏，hover 时显示
└──────────────────────────────┘
  - 下载：输出原始 PNG 文件，不压缩
  - 复制：原始 PNG 写入剪贴板
  - 编辑：基于此图 + 新 prompt 调用 /v1/images/edits

多张图片时（n>1）：
┌─────────┬─────────┐
│  img 1  │  img 2  │
├─────────┼─────────┤
│  img 3  │  img 4  │
└─────────┴─────────┘
2×2 网格，间距 8px，每张可独立操作

图片放大预览（Lightbox）：
  - 点击图片 → 全屏遮罩 + 居中大图（**原始 PNG，不压缩**）
  - 支持左右键切换同组图片
  - 点击遮罩 / ESC / 右上角 × 关闭
  - 底部操作栏：下载原始 PNG | 复制原始 PNG | 显示尺寸信息（如 "1024 × 1024"）
  - 图片来源于 IndexedDB 中的原始 Blob，不经过任何二次压缩
```

```
用户消息（右对齐）：

│                         ┌───────────────────┐    │

  - 圆角：12px，右下角 4px（指向用户）

AI 消息（左对齐）：
┌──────────────────────────────────────────────────┐
│  ┌───────────────────────────────────────┐       │

└──────────────────────────────────────────────────┘
  - 背景：#FFFFFF，边框：1px solid #E5E5E5
  - 圆角：12px，左下角 4px（指向 AI）
```

### 5.4 侧边栏会话列表

```
┌─ 会话列表 ──────────────────┐
│ [🔍 搜索会话...]            │

```

## 6. 动效规范

| 交互 | 动效 | 参数 |
|------|------|------|
| 侧边栏展开/收起 | 宽度变化 | 280ms, ease-out |
| Settings 面板滑出 | 右侧滑入 | 300ms, cubic-bezier(0.32,0.72,0,1) |
| 图片加载完成 | 淡入 | 300ms, ease |
| 会话切换 | 内容交叉淡出 | 200ms, ease |
| 骨架屏 | 脉冲闪烁 | 1.5s, infinite, ease-in-out |
| 按钮 hover | 背景色变化 | 150ms, ease |
| 弹窗/toast | 从下方弹入 | 200ms, spring(1,80,10) |
| 删除确认弹窗 | 缩放+淡入 | 200ms, ease-out |

**原则：所有动效 < 400ms，不使用弹跳类过度动画，保持克制。**

## 8. 异常状态设计

### 8.1 网络错误

```
┌──────────────────────────────────────┐
│  ⚠️ 网络连接失败                      │
│  请检查网络后重试                      │
│                          [重试]       │
└──────────────────────────────────────┘
  - 出现在消息流中，替代 AI 回复位置
  - 红色左边框 + 浅红背景
```

### 8.2 API Key 无效

```
┌──────────────────────────────────────┐
│  🔑 API Key 无效                      │
│  请检查你的 API Key 是否正确           │
│                     [去设置]  [重试]   │
└──────────────────────────────────────┘
```

### 8.3 内容审核拦截

```
┌──────────────────────────────────────┐
│  🚫 无法生成此内容                     │
│  你的描述可能包含不支持的内容，          │
│  请修改后重试                          │
│                          [修改描述]    │
└──────────────────────────────────────┘
  - 点击 "修改描述" → 将原 prompt 填回输入框，用户可编辑后重发
```

### 8.4 余额不足

```
┌──────────────────────────────────────┐
│  💳 API 额度不足                      │
│  请前往 OpenAI 控制台充值              │
│                     [前往充值 ↗]       │
└──────────────────────────────────────┘
```

## 9. 响应式断点

| 断点 | 布局变化 |
|------|----------|
| ≥1200px | 侧边栏常驻 + 对话区 + Settings 面板三栏并存 |
| 768-1199px | 侧边栏可折叠，Settings 覆盖对话区右侧 |
| <768px | 侧边栏抽屉化，Settings 全屏弹窗，输入框简化 |

## 10. 路由结构

```
/                → 主界面（对话 + 侧边栏）
/chat/:id        → 指定会话（URL 可分享/书签）
/gallery         → 图片画廊（v0.2）
```

Settings 不占路由，通过面板/弹窗实现，不影响主路由状态。
